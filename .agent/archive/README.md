# Archive

This folder stores archival ExecPlans, prompts, and reference material that should not affect the context of agents.

## If you are an AI

- Do not read any files from this folder unless explicitly asked to reference it.

## What belongs here

- Finished ExecPlans that have been moved out of the working `.agent/` folder
- Archived prompts used for one-off data collection
- Reference material that should stay out of working context

## Rules

- Keep files read-only unless you are intentionally updating the archive
- Do not place production docs or app content here
- This folder is ignored by Copilot via [.copilotignore](.copilotignore)
