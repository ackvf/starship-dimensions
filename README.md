# Starship Dimensions

Interactive SvelteKit app for comparing starship sizes across universes with pan/zoom fleet visualization, filters, draggable silhouettes, metadata modals, and markdown-based ship uploads.

## Development

```sh
pnpm install
pnpm dev
```

Open `http://localhost:5173`.

## Checks

```sh
pnpm check
pnpm test
pnpm lint
```

## Ship files

Ship definitions are markdown files with YAML frontmatter.

See [SHIP_FORMAT.md](./SHIP_FORMAT.md) for the exact schema and example.
