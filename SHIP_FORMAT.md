# Ship File Format

Ship files are Markdown documents with YAML frontmatter. The frontmatter holds the structured metadata used by the app, while the Markdown body is rendered in the ship details modal.

## Required frontmatter fields

- `name` (string)
- `universe` (string)
- `lengthMeters` (positive number)
- `tags` (array of strings)

## Optional frontmatter fields

- `id` (string, autogenerated from `name` when omitted)
- `images.main` (string URL, placeholder generated when omitted)
- `images.silhouette` (string URL, placeholder generated when omitted)
- `images.gallery` (array of string URLs)
- `links` (array of `{ label, url }`)

## Example

    ---
    id: example-cruiser
    name: Example Cruiser
    universe: Exampleverse
    lengthMeters: 950
    tags: [cruiser, capital]
    images:
      main: https://dummyimage.com/900x180/111827/f8fafc&text=Example+Cruiser
      silhouette: https://dummyimage.com/900x180/020617/94a3b8&text=Example+Silhouette
      gallery:
        - https://dummyimage.com/960x540/1f2937/e5e7eb&text=Hangar+Bay
        - https://dummyimage.com/960x540/0f172a/cbd5e1&text=Bridge
    links:
      - label: Wiki
        url: https://example.com/wiki
    ---
    A markdown description of the ship.

## Notes

- Uploaded ships should use externally reachable image URLs.
- Curated built-in ships may reference local assets from `static/`.
- You can use the project skill at `.codex/skills/ship-file-creator/SKILL.md` for an authoring checklist.
